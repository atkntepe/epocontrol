Lighting

Effects and ranges are the driver's list for this board (Yy.light.types). Music-follow and screen-colour need host streaming and are not offered. Badge/side light: the driver has no side-light config for this board, so use Fn+PgUp / Fn+Home on the keyboard.

Per-key RGB

Queue: idle

Click keys to paint. Uploads go to flash and are paced to at most 2 per 10 s (sharkfin), then the effect switches to User Picture after a 2 s settle. Read-back of per-key colour is not reliable on these boards, so it is not used to verify.

Keymap

Pick a key.

The first write in a session automatically downloads a backup of all 6 layers (3 profiles × base/Fn) before writing. Each write is 9 pages (driver JC._setKeyConfig) and is verified by reading the layer back. Changed keys are outlined.

Macros

Recording captures key down/up and the gaps between them from this browser window. Encoding is a line-by-line port of the driver's eF.setMacro (256-byte buffer); writes use BGe._setMacro (opcode 0x16, pages of 56 bytes) and are verified by reading the macro back (0x8B).

Profiles

Same as Fn+Z / X / C. Switching is verified by reading the active profile back (0x85).

Settings

Keyboard options (read-modify-write, per active profile)

Only these 3 bits and the power-save byte are ever changed. Every other bit is copied from a fresh read. The keyboard-lock bit (0x80) is forced to 0 and asserted in code. Mac/Win is shown read-only because the driver's setter and getter disagree on its bit.

Debounce

Sleep timers (minutes, 2.4G / Bluetooth only)

Info

Polling rate is read-only here. Battery level: the driver has no battery command for this board over the cable, so it is not shown.

Factory reset

Resets all profiles, lighting, keymaps and macros (driver JF.setReSet, opcode 0x02). Make a full backup first.

Backup & restore

Reads lighting, active profile, options for all 3 profiles, debounce, sleep timers, all 6 keymap layers, every macro they reference, and the per-key colour buffer.
